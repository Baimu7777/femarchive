主要形容这种帖子每个月都会被讨论，以抱着在虜社对月经有贬义的态度，所以叫月经贴是不是本身也带有贬义成分？

{{< commentsection title="评论交流区" >}}

{{< card >}}
是什么场景说的呢？如果是女权er说的，那可能代表某个反复讨论但没有解决的问题很有交流价值吧，所以才会被常常拿出来讲。如果是虜说的，肯定有贬义意味。我还是第一次听说这个词 不过我的观感倒没感受到什么贬义。
{{< /card >}}

{{< card >}}
我的体感是一个非褒非贬的存在吧，就是说一个话题反复被提到？
{{< /card >}}

{{< card >}}
把反反复复没有解决的问题与月经相连，就好像在暗示月经本身也是一种反反复复未能解决的问题。月经贴代表的是未解决反复出现的问题，月经也是吗？如果是指代那种非负面含义，只是经常会出现的话题，那才算得上中性含义。

不过可能有些人是从讽刺意出发吧，形容这些事件就像月经一样总是被视为不重要的，被轻视的，却又反复出现的。但我还是不喜欢这种将月经与负面消息感官挂钩的联系。
{{< /card >}}

{{< card >}}
说不上来，但觉得有点奇怪。
