其实做过一次就知道了，以后都不想碰。但有时候在观阅某些影视作品or愉乐作品时，总是想看到女本位的翻译，至少不是线头藏不住地满天飞。但制作汉化又费心费力，实在不讨好。总的来说正反馈太少。

{{< commentsection title="评论交流区" >}}

{{< card >}}
我觉得很多文愚影视作品都是为市场而拍的，因为成本比较高，肯定有经济团体的介入，还要符合市场利益，很少有完全激进彻底的电影，总而言之就是虜或者虜厷一起拍的平权片，以我个人的观点，我认为没有必要看这种片子。
{{< /card >}}

{{< card >}}
像汉化那个弱役赛跑就行，毕竟毕竟那是女权做的。要汉化也是汉化其她语言的女权作品，方便宣传和输出。
{{< /card >}}

{{< card >}}
有道理。
{{< /card >}}

{{< card >}}
汉化翻译行为本身只是一个客观行为，想要与外交流，翻译工作也难免。（指做更女本位化翻译工作，这的确需要一番工夫）问题是翻译的作品老是那些其实根本都不合格的作品，那把时间投入其中，就是做无用功，更何况，大把虜会去翻译这种温和作品作为自己仿佛又女权一点的赎罪券，我们就更没必要参与。

像是最开始从韩国传过来的bt，没人翻译也传播不开。还有之前看推上有同姃翻译反争禁的那张图，我想，我们也应该不仅要翻译外文区的女权思想，也要把我们的思想翻译宣扬。所以从这个角度看，我们还是需要翻译的。只是重点前提是这思想或者作品至少真的是女权相关。
{{< /card >}}
