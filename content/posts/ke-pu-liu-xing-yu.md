有时看到盟友会无意识地用这些口癖，并不是针对用过的朋友，希望大家以后能互相科普。也许这些梗跟“气抖冷”这种直接的轻蔑与嘲弄相比，还算没那么辱女，但它们所诞生的语境，不应该具有娱乐化的情绪。

# **“非常好xx”/“非常好xx，使我xx旋转”**

## **“非常好xx”**

出自老钟人使用拙劣的英语给成人网站p站的视频评论：

{{< card >}}
Very good video, love. （用户ip地址from china）
{{< /card >}}

{{< card >}}
机翻之后，就会译为：非常好视频，爱来自钟果/瓷器。
{{< /card >}}

## **“使我xx旋转”**

出自南通题材成人动画《Axel in Harlem》。为了表现男人们对男主的垂涎欲滴，便有了“领结旋转”这种夸张的表现形式。

![](/images/posts/kepu01.webp)

# **“你有这么高速运转的机器进入钟果”**

某位东北的大姐在进小区的时候，被门卫拦下。她情绪激动之中说出了一段匪夷所思、语无伦次的话，被视频录下发到网上后爆火。

![](/images/posts/kepu02.webp)

{{< card >}}
“你有这么高速运转的机器进入钟果，记住我给出的原理小的时候，就是研发人研发这个东西的管理。”“黄龙江一派全部带蓝牙，黄龙江我告诉你是那个化名，化名我小舅，亲小舅”
{{< /card >}}

显然，这位女士有很大的可能性患有韦尼克失语症，并且有轻微的精神问题。这个梗就算没那么辱女，对当事人没那么强的攻击性，它也并不好笑。处于紧张激动之中的神经疾病患者，说出的话成为爆梗笑料、被全国人模仿，这种流行风尚，非常残酷、漠然。

就像之前有个男的接受采访，他想说“被一拳打到了上颚上”，由于文化水平不够，只知道下巴这个词，说成了“被一拳打到了上巴上”。没接受过多少教育、面对镜头采访紧张无措，这样一个受访者，爆出了好笑的金句梗，难道真的好笑吗？但这个梗辱的是v。所以我不在乎，我在知道其残酷性的情况下，依然觉得好笑。

# **“世界是一个巨大的xx”**

一开始是由于女网友感叹“世界是一个巨大的爱/丁/堡”，被喜爱跟风、百无聊赖、喜欢嘲弄爱女思想的落体人们拿过去，娱乐化为各种“世界是一个巨大的xxx”，消解了这句话的严肃批判含义。诞生过程类似“气抖冷”。

# **“你也不想xxx吧?”/“你也不想xxx被xxx知道吧?”**

出自日本成人影片的常见台词。

{{< card >}}
“xxx夫人，你也不想那件事情被你先生知道吧?”
{{< /card >}}

胁迫，困境，下作，与好笑无关。

# **“已经成为了xxx的形状”**

出自日本本子文化的常见台词。

{{< card >}}
字面意思就是，由于ml次数太多，女人下体变成了v的器官的形状。
{{< /card >}}

{{< card >}}
引申含义是，某女人已经是某人的所有物了👉某女人身心只被某人彻底拥有👉某人对某套理论、行为模式完全顺从，完全忠诚，被打上了思想烙印。
{{< /card >}}

将自己代入虚构的女子，来合理化、自怜自己的善于服从、膝盖骨软、苟且偷生、后方敞开、压抑愤怒行为，古有小诗人，今有二次元神人。
