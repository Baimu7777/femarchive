# 一、小组立场

本组所有成员均认可并践行12bt，包括反性缘部分。

*注：{{< hl >}}11是不与男进行非利益交谈，12是不与虜进行非利益交谈。{{< /hl >}}*

# 二、组规

1. 推广女义词的使用（[素材&方法｜关于改字 女字去污名化（内附女义字、女本位合集不断更新中） ](https://www.douban.com/group/topic/300483081/)）
2. 组内禁阍恋、弱役、追星话题

    1. 全男主角书影

# 三、小组管理方式

1. **进行共治，所有人都有管理权限。因此所有小组成员应当认可并践行12bt，包括反性缘部分**。
2. [组长号](https://www.douban.com/people/293119797/)将不再继续发言使用。
发布组规、投票等，都直接使用个人号发布，鼓励所有人参与建设，用发言代替赞来表达自己的态度，用行动代替观望与等待她人。有不满意的地方大胆表达，这也是共治的初衷。希望大家都能加一把手，建设自己想要的小组，而不是等待别人做好别人想要的小组再加入。**一组不建设何以建设新世界。**
3. 对新入组成员，所有现成员都可对其进行审核。申请时的答题结果需进行留档，具体流程详见[组内事务帖-成员审核](https://herarchive.feminism-nv.space/affairs/)部分。
4. 成员互相监督。豆瓣管理后台可以看到所有操作详情记录，如果有人对其她人的操作有任何异议都可以提出。在组内设立一种共识，即能加入这个组的姐妹都是希望进步的，如果看到有不舒服的地方尽管直说，能改则改，不改则提议修订组规，开投票楼对组规条例进行扩充。**尽量不要用驴这种称呼随便攻击组员**。
5. 加入 **“成员去留表决”** 制度，任一成员有某成员厌女或违反组规的证据，可以直接开楼表决是否踢出（支持跨组执法）。
6. [杉.](https://www.douban.com/people/293119797/)这个号会始终保持至少有三个组员有账户密码，暂时不用太担心会出现一言堂、随意踢人或其她问题。该账号目前已封存，不处理除邀请成员成为管理员以外的任何事务。

# 四、发帖与回帖

1. 有新的组规建议可在组规建议楼讨论，若认为有必要可直接开组务楼，进行一周的共示，期间没人提出异议就可以落实。落实后添加到组内必看帖的评论区（此帖正常情况下设置为不可回复）；
2. 发帖人自行设置帖子**限制回复-仅组内人回复**，若忘记设置，其她人可帮忙设置；
3. 发帖前选择分区，**{{< hl >}}我共建{{< /hl >}}**分区为组务版块，**{{< hl >}}我评判{{< /hl >}}**分区为作品打分板块，其她内容均可发在**{{< hl >}}我茶话{{< /hl >}}**分区；
4. 闲聊、资讯、批评帖主楼内容不少于30字；打分帖需附上打分表图，无最低字数要求。

# 五、违禁行为

1. [违反成员要求](#六成员要求需全部满足)；
2. 在其它小组发布非女作者作品或非女主作品正向评论；
3. 泄露组员个人隐私；
4. 人身攻击成员；
5. 外泄其她组员的入组申请答案。
